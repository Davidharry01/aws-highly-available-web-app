# Highly Available AWS Web Application

## Project Overview

This project demonstrates the design and deployment of a highly available and scalable web application infrastructure on Amazon Web Services (AWS).

The application will be deployed across multiple Availability Zones to provide high availability and fault tolerance.

## Project Goals

- Build a custom AWS VPC
- Configure public and private subnets across multiple Availability Zones
- Configure routing and internet connectivity
- Deploy EC2 web servers
- Configure an Application Load Balancer
- Implement EC2 Auto Scaling
- Deploy an Amazon RDS database
- Apply security groups and IAM best practices
- Configure monitoring with Amazon CloudWatch
- Test high availability and fault tolerance
- Document the architecture and deployment process
